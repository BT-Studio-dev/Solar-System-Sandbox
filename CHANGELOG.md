# Changelog

## 2.0.0 — Aero Observatory

- Added TRAPPIST-1: an exoplanet scenario with seven worlds and approximate published orbital periods, radii, and masses.
- Expanded the Solar System catalogue with the interstellar visitor 1I/Oumuamua.
- Added portable, versioned JSON export/import so experiments can be moved between device profiles. Imports are size-limited and validated before changing the current session.
- Added keyboard selection with Left/Right arrows and preserved compatibility with locally stored 1.1-era experiments.
- Bumped the Windows desktop and Android preview packages to 2.0.0; retained Classic Sandbox and the Windows 7 legacy runtime.
- Added model and automated UI coverage for exoplanets, file portability, compatibility migration, and rejection of invalid imports.

## 1.1.0 — Aero Simulator

- Added the Aero screenshot-inspired simulator, six initial scenarios, local parts library, procedural colour packs, and five themes.
- Added orbital rails, optional gravity integration, UTC date controls, focus/follow camera, and body creation.
