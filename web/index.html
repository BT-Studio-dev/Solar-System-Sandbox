SOLAR SYSTEM SANDBOX · AERO

Your universe, a new perspective.

Version 2 adds the TRAPPIST-1 system and portable experiment files. The original gravity sandbox remains available from the title bar.

Explore
Click a body to inspect. Left-drag to pan; right-drag to rotate the orbital plane. Scroll or pinch to zoom. Use the body selector for distant worlds.
Create
Choose one of eight body types, adjust mass, radius and orbit, then add it. New bodies use gravity; existing bodies stay on approximate Keplerian rails.
Focus / Follow
Focus zooms toward the selected body. Follow keeps it centered. Use the reset-camera button to return to the overview.
1D / 2D / 3D / 4D
Choose a radial line, a flat orbital plane, the spatial view, or a 4D-inspired time projection. In 4D mode, dotted tethers link each projected object to its 3D reference position; this is a visualization, not physical fourth-dimensional gravity.
Gravity
Release one body or switch primary bodies to live gravity. Moons stay on parent-relative rails unless individually released. No collision merging.
Library & portable files
Save custom parts locally, switch colour packs, or use a scenario. Export/Import JSON transfers a validated version 2 experiment between devices; imported files are limited to one megabyte.
Controls
Space: play/pause · ←/→: select bodies · C: settings · F1: help · F3: theme · Escape: close panels · +/−: zoom. Save/Load keep one local experiment; Export/Import JSON transfers a portable save.

Dates drive approximate orbital elements, not observed real-time positions. Moon distances and body sizes are exaggerated unless True sizes is enabled. Offline. No accounts or tracking.
